# Site — Rafaella Camila Peixoto de Freitas

Portfólio profissional em HTML, CSS e JavaScript, com identidade visual suave e linha do tempo da trajetória acadêmica e profissional.

## Arquivos deste pacote
- `index.html` — conteúdo e estrutura das páginas.
- `estilo.css` — cores, layout e responsividade.
- `script.js` — interações do menu e elementos da página.
- `foto-rafaella.jpeg` — foto usada na página inicial.

## Publicar no GitHub Pages
1. Baixe e extraia este ZIP.
2. Acesse https://github.com/StiflerPetti/Site-Rafaella-Camila
3. Clique em **Add file → Upload files**.
4. Envie os cinco arquivos extraídos, substituindo os arquivos de mesmo nome.
5. Clique em **Commit changes** e aguarde alguns minutos.
6. Confira https://stiflerpetti.github.io/Site-Rafaella-Camila/

**Importante:** mantenha os arquivos na raiz do repositório, sem colocá-los dentro de uma subpasta. A área de estudos é apenas uma prévia visual e ainda não tem autenticação ou banco de dados.
