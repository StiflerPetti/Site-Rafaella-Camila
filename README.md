# Site Rafaella Camila

Prévia inicial do portfólio profissional responsivo da Rafaella Camila.

## Publicar no GitHub Pages
1. Envie `index.html`, `style.css` e `script.js` para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, salve e aguarde a publicação.

A área de estudos é apenas uma prévia visual nesta versão. Não há autenticação nem banco de dados ligados ainda. Não publique informações pessoais sensíveis.
