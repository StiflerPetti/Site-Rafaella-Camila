# Site Rafaella Camila

Site profissional pessoal de Rafaella Camila Peixoto de Freitas.

## Publicar atualização no GitHub Pages
1. Extraia todos os arquivos deste ZIP.
2. Abra https://github.com/StiflerPetti/Site-Rafaella-Camila
3. Clique em **Add file → Upload files**.
4. Envie os arquivos extraídos, substituindo os arquivos de mesmo nome.
5. Clique em **Commit changes** e aguarde alguns minutos.
6. Confira https://stiflerpetti.github.io/Site-Rafaella-Camila/

Mantenha `index.html`, `estilo.css`, `script.js` e `foto-rafaella.jpeg` na raiz do repositório. A linha do tempo da seção **Minha trajetória** é desenhada pelo CSS em `estilo.css`.
